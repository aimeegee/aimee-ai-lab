# aimee-ai-lab 团队 v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `aimee-ai-lab` 里搭出一个由 lead 带领 PO/BA、Engineer、Tester 的 Claude Code 团队,并能在任意 session 里用 `/lead` 调用。

**Architecture:** 团队是一组 markdown 规则文件(`CLAUDE.md`、`team/`)加几份共享记录文件(`ideas.md`、`decisions.md`、`boss-preferences.md`)。lead 就是当前 Claude Code session,按 `team/lead.md` 行事;派活时读 `team/roster.md` 和角色文件,用 Agent 工具派出通用 subagent。全局入口是一个用户级 skill(源文件在 repo 里,用脚本 symlink 安装)。行为用 `claude -p` 在临时沙箱 repo(本地 bare remote,不碰 GitHub)里跑冒烟测试来验证。

**Tech Stack:** Markdown、bash、git、`gh`、`claude` CLI 2.1.x、`rsync`、`python3`(仅用于校验 JSON)。不引入新依赖。

**Spec:** `docs/design.md`

## Global Constraints

- 团队 repo:`/Users/naixingeng/Develop/aimee-ai-lab`,GitHub `aimeegee/aimee-ai-lab`
- 构建本身在分支 `build/team-v1` 上进行,完成后开 PR 给 Aimee review
- 只用 Claude:`roster.md` 中「执行者」唯一合法值为 `claude`
- 默认模型:Lead = `session`(当前 session 模型),PO/BA = `opus`,Engineer = `sonnet`,Tester = `sonnet`;合法值 `opus` `sonnet` `haiku` `session`
- 五类必问(逐字写入 lead.md):1 改变「做什么」:范围、目标、验收标准;2 花钱:付费服务、API 订阅;3 对外可见:例如 bot 首次回复真实用户、发邮件、公开发布;4 不可逆:删数据、删 repo、force push;5 碰私人账号:银行、个人 Drive 等
- 五类必问即使偏好能推断也必须问;此时带着推荐来问
- project slug 匹配 `^[a-z0-9-]+$`;分支 `project/<slug>`;worktree 在 `.worktrees/<slug>`(gitignored)
- `projects/<slug>/STATUS.md` 和 `requirements.md` 只在 `main` 上修改,project 分支不碰它们(lead 在主 checkout 读进度)
- 共享文件(`ideas.md` `decisions.md` `boss-preferences.md` `team/**` `projects/*/STATUS.md` `projects/*/requirements.md`)由 lead 直接 commit 到 `main` 并 push,commit 信息前缀 `team:`;写之前 `git pull --rebase origin main`
- Engineer/Tester 不执行 git commit/push;由 lead 在 Tester 通过后提交到 project 分支,前缀 `<slug>:`
- 新 GitHub repo 一律 `--private`;改为 public 属于必问
- 任何密钥不进 repo

## Review Focus

1. 两个 session 先后写 `main`(本地落后于 remote)→ lead 应先 rebase 再 push,不丢任何一方的改动。测试:Task 1 `test_main_behind.sh`
2. 「开始做 X」里的 X 不对应任何已有 idea → 新建 project,不应错套到别的 idea 上。测试:Task 4 `test_start_unknown_idea.sh`
3. 中途关掉 session 再回来 → 从 `STATUS.md` 恢复并继续,而不是从头开始。测试:Task 6 `test_e2e.sh` 第二次调用
4. 中文或带空格的项目名 → slug 仍是合法 ASCII kebab。测试:Task 4 `test_start_project.sh` 的 slug 断言
5. 下属在执行中撞到五类事(例如需要付费 API)→ lead 必须上报,不能因为偏好就自己定。测试:Task 2 `test_must_ask_escalation.sh`
